# File Hub 页面设计稿

本目录存放第一阶段的五个核心页面设计参考。页面保持轻量，所有操作围绕“发现文件 → 补充标记 → 进入文件库”闭环。

| 文件 | 页面 | 关键交互 |
|---|---|---|
| `01-dashboard.webp` | 首页概览 | 统计卡片和待处理提醒跳转到对应列表 |
| `02-download-monitoring.webp` | 下载监听 | 筛选来源；待标记文件可立即标记或忽略 |
| `03-pending-tagging.webp` | 待标记 | 保存标记、保存并入库、忽略文件是不同操作 |
| `04-file-library.webp` | 文件库 | 只展示成功入库文件；可查看详情、编辑标记 |
| `05-settings.webp` | 设置 | 明确配置监听程序 EXE、监控方式、监听目录和提醒规则 |

设置页的“监听程序”是必需区域：用户通过“添加程序”选择 EXE，选择浏览器下载事件、目录监听、进程 I/O 辅助监控或组合模式，并能启用/停用规则。目录监听是补充方式，不能假定所有客户端使用同一个下载目录。

> 设计稿用于讨论界面和交互，不代表截图中的示例文件、数字或客户端状态是真实运行数据。

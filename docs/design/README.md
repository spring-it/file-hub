## 其余核心页面的设计与交互约定

| 页面 | 关键交互 |
|---|---|
| 下载监听 | 筛选全部 / 浏览器 / 客户端；待标记文件可立即标记或忽略；已忽略或已入库记录可查看 |
| 待标记 | 左侧待标记队列，右侧填写项目、业务版本号、预计发送对象、预计发送时间、标签和备注；支持保存标记、保存并入库、忽略 |
| 文件库 | 仅展示成功入库文件；支持查看详情、编辑标记、打开文件位置 |
| 设置 | 必须包含“监听程序”区域，用户通过“添加程序”选择 EXE，设置监控方式与启用状态；另有“监听目录”和“提醒与过滤” |

## 交互闭环规则

- **保存标记**：保存业务信息，状态为“已标记 / 待入库”。
- **保存并入库**：先保存标记并复制到受控仓库，成功后才标记为已入库。
- **忽略文件**：确认后设为已忽略，并保留操作记录。
- **稍后处理**：只关闭编辑视图，文件仍在待标记队列。
- 设置页“监听程序”支持用户添加、编辑、启用、停用和删除程序，并配置浏览器下载事件、目录监听、进程 I/O 辅助监控或组合模式。
- 目录监听是补充方式，不能假定所有客户端使用同一个下载目录。
- 截图中的示例数据仅用于设计讨论，不代表真实运行数据。

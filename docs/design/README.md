# File Hub 页面设计

当前客户端使用四个主要页面，下载监听与待标记已合并为同一个工作区：

| 页面 | 交互闭环 |
|---|---|
| 首页概览 | 统计数字跳转到相应工作区；最近文件可标记、忽略或查看 |
| 下载监听与标记 | 左侧查看和筛选下载记录，右侧选择文件并填写项目、版本、预计收件人和时间；保存标记与保存并入库分开执行 |
| 文件库 | 仅显示成功入库文件，可查看详情、编辑标记、打开文件位置 |
| 设置 | 添加/编辑/启停/删除监听 EXE；配置目录、递归监听、文件类型和通知设置；非浏览器客户端可选 ETW 组合模式 |

**保存标记**不会自动入库。只有受控副本成功创建并校验内容后，才标记为已入库。

新文件提醒使用 Windows 原生通知；点击通知打开 File Hub 并定位到对应文件标记。高频下载会合并通知数量，但每个文件仍单独记入台账。

# File Hub 页面设计

第一阶段只保留五个主要页面：

| 页面 | 交互闭环 |
|---|---|
| 首页概览 | 统计数字跳转到对应列表，最近文件可标记或查看 |
| 下载监听 | 查看来源、路径、时间；待标记文件可标记/忽略；已忽略文件可恢复 |
| 待标记 | 填项目、版本、预计收件人和时间；保存标记、保存并入库、忽略分别执行不同状态迁移 |
| 文件库 | 仅显示成功入库文件，可打开文件位置 |
| 设置 | 必须有“监听程序”区，添加/编辑/启停/删除 EXE；另有监听目录和提醒过滤设置 |

**保存标记**不会自动入库。只有受控副本成功创建并校验内容后，才标记为已入库。

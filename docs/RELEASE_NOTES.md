# File Hub v0.2.0 — Windows MVP 预览版

## 本版本变化
- 合并“下载监听”和“待标记”为单一工作区，下载列表与标记表单并排显示。
- 使用 Windows 原生通知提醒新文件；通知点击打开对应文件的标记工作区，并对短时间下载洪峰进行通知合并。
- 增加可选 .NET 10 ETW Agent；用户可在设置中为非浏览器客户端选择“进程 I/O + 目录”，启用或重新启动进程监听时需通过 UAC。
- 增加进程路径匹配、子进程关联、事件去抖、并发与洪峰保护。
- 增加 Windows CI 的 ETW Agent 构建、自测和条件式内核事件冒烟测试。

## 安装与使用
下载附件 `FileHub-Setup-0.2.0.exe`，在 Windows x64 上运行。
- Edge/Chrome 需要安装 `resources/extension` 浏览器扩展并启用浏览器规则。
- 普通客户端可使用目录监听；如需捕获未知保存目录的写入，可尝试“进程 I/O + 目录”，批准管理员授权后生效。
- Windows 系统设置若关闭 File Hub 通知，应用无法强制显示 toast。

## 已知限制
- ETW 与第三方辅助进程、文件重命名、网络盘、长时间运行的兼容性仍需在目标用户电脑验收；CI 不等同于所有企业客户端实机验证。
- 内部网页外发集成尚未实现。
- 安装包未进行代码签名，Windows SmartScreen 可能提示未知发布者。

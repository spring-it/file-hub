# File Hub v0.1.0 — Windows MVP 预览版

## 已包含

- Windows Electron + React 客户端：**首页概览、下载监听、待标记、文件库、设置**五个页面。
- 在“设置”中添加或编辑监听客户端 EXE、关联监听目录、递归开关和提醒过滤选项。
- 浏览器（Edge/Chrome）下载扩展与 Native Messaging 通道的实现。
- 本地目录监控、文件写入稳定性检查、异步 SHA-256、事件去重、补偿扫描和限流。
- 待标记队列、文件业务标记、保存并入库、忽略/恢复、文件库编辑标记。
- SQLite 本地台账、操作记录、Windows 托盘和通知点击定位。
- Windows NSIS 安装包，构建前执行自动化测试及 TypeScript 检查。

## 下载与安装

下载附件 **FileHub-Setup-0.1.0.exe**，在 Windows 10/11 x64 上运行安装程序。

默认可使用“设置 → 监听目录”添加常用下载文件夹。监控其他桌面程序时，请添加该程序实际保存文件的目录。

**浏览器监听另外需要安装浏览器扩展：** 开启浏览器扩展页面的开发人员模式，加载安装目录下 `resources/extension`，然后在 File Hub 设置里启用 Chrome/Edge 的程序规则。详见仓库 [README](https://github.com/spring-it/file-hub/blob/main/README.md)。

## 预览版已知限制

- 普通桌面客户端目前依赖用户指定保存目录；**尚未实现 ETW 进程级任意目录检测**。添加一个 EXE 不代表能捕获其所有下载。
- 内部网页发送功能计划在第二阶段对接，本版本只管理文件和预计发送信息，不执行实际发送。
- 自动测试与 Windows CI 构建可以验证核心逻辑和生成安装包，但 **真实 Windows 电脑的安装、浏览器扩展联动、客户端兼容性及持续运行性能仍需使用方验收**。
- 未对安装包进行代码签名；Windows SmartScreen 可能提示未知发布者。

如遇问题，请在仓库的 Issues 中提交具体 Windows 版本、客户端版本、复现步骤与错误提示（请勿上传敏感文件本身）。
